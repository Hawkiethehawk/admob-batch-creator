## 单页与多页

面板支持 1～5 个执行页、默认 5。多页必须先通过当前会话的跨页身份、GM 通知和 Web Locks 检测。HubVPS 的 `GM_openInTab` 曾出现探测页空白、握手超时；0.4.8 在探测期间提供“打开执行页”链接，可在原浏览器配置中补开该页，探测结束后链接清除。

自动化接入时，Playwright 在原 HubVPS 的同一 context 中打开链接，继续使用原脚本的 hello、跨页锁、通知、身份检查和任务调度。宿主 `data-manual-tabs` 可跳过 `GM_openInTab` 自动开页；它不跳过任何能力或提交检查。此次 5/5 正是该开页方式，并轮流 `bringToFront` 避免后台节流；默认自动开页只做源码审查，全部长期后台或最小化未实测。Playwright MCP 的扩展连接与本轮桥维护方法另见 [Playwright浏览器控制.md](../Playwright浏览器控制.md)。

新批次多页预检先预热独立执行页，每页分别完成握手。若上一已结束批次存在同发布商、应用和格式的合格成功样本，预检按精确 ID 重新核验全部保存配置，一致才复用首条门控并按所选并发派发新清单；无样本仍先核验首条，复核失败不放行。暂停批次无待核验项时，按剩余任务需要的页数预热，上限为所选并发。预热与样本复核均不提交广告位。

0.4.14 的全新五条批次已一次开始并自动完成 5/5 保存后核验，五任务共同活动至少 27.981 秒，期间无人工提交、补录、重试或手动核验。该次先复核历史成功样本，不能据此保证没有样本的冷启动也同时运行五任务。0.4.13 的旧五条仍保留 4 成功、1 条提交前失败的历史。能力不可靠时保持单页，并保留探测错误。单页同样要求可靠的主控互斥。

## Windows Chrome / Edge

在日常登录目标 AdMob 的浏览器配置中，从 [Tampermonkey 官网](https://www.tampermonkey.net/) 安装扩展，核对扩展启用、网站访问和用户脚本执行权限，再导入同一安装文件。脚本不在 Google 登录页运行；会话过期时在原浏览器恢复登录，返回原发布商与原应用重新识别。

脚本不读取或导出 Cookie、Token、密码、验证码及完整登录数据，不调用私有接口，不修改付款币种。更多执行和恢复说明见 [使用说明](USAGE.md) 与 [适配限制](adapter-limitations.md)。

当前正常运行验收不包含暂停、睡眠、主控或执行页在途刷新。许可检查到原生点击间仍有异步空档，暂停/停止不能绝对撤销已通过检查的任务；条件性源码边界详见适配限制。
