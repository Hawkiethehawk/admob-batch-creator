## 并发与串行

“并发”为默认方式。确认后，插件一次打开所有待执行行对应的 `/adunits/create` 页，并按清单顺序激活。当前页完成创建、保存后读回和关闭后才进入下一页。“串行（当前页逐条执行）”在原页处理任务。

可用“检测跨页能力”检查并发开页、前台切换和关页。出现开页故障时，面板会显示启动结果并保留编辑清单。[验证记录](VALIDATION.md)

## Windows Chrome / Edge

在日常登录目标 AdMob 的浏览器配置中，从 [Tampermonkey 官网](https://www.tampermonkey.net/) 安装扩展，核对扩展启用、网站访问和用户脚本执行权限，再导入同一安装文件。脚本不在 Google 登录页运行；会话过期时在原浏览器恢复登录，返回原发布商与原应用重新识别。

脚本不读取或导出 Cookie、Token、密码、验证码及完整登录数据，不调用私有接口，不修改付款币种。更多执行和恢复说明见 [使用说明](USAGE.md) 与 [适配限制](adapter-limitations.md)。

当前真实验收范围不包含完整暂停、睡眠、主控或执行页在途刷新流程。点击前同步复查状态、归属和许可已实现，已经发出的请求仍须收集结果；执行页角色恢复等边界见适配限制。
